# 8086-voltage-monitor
烟大计控微机原理课程设计。基于 8086、ADC0808、8255A 和 8253，在 Proteus 中演示双路电压采集、上下限判断、按键控制与声光报警。
# 基于 8086 与 ADC0808 的双路电压监控系统

本项目是微机原理课程设计，使用 Proteus 和 8086 汇编演示双路电压监控，
供同学学习 A/D 转换、并行接口、定时器与报警逻辑。

## 设计内容

- 使用 ADC0808 采集两路模拟电压，通过 8255A 读取转换结果。
- 使用 8253 提供定时控制，通过按键选择显示通道。
- 分别控制上限和下限报警的启用状态。
- 检测到启用的越界条件时，驱动扬声器和 LED 报警。

## 查看工程

下载并解压仓库，在 Proteus 中打开 `diany2.pdsprj`。
汇编源码供阅读和修改。重新编译前，如遇源码路径提示，
请在 Proteus 中重新关联下载目录里的 `.asm` 文件。

建议分别调节两路输入，观察正常、超上限和低于下限时的表现，
再切换上下限报警开关，对照汇编中的判断逻辑。

## 阈值说明

`2.asm` 中的上限和下限分别定义为 `B0H` 和 `50H`。
题目中的 `80H` 是换算示例：按 0～5 V 量程计算，
2.5 ÷ 5 × 255 = 127.5，取整为 128（`80H`）。
